# Subject-Identity-Preservation
A Pipeline created for the Open-Source model OmniGen which takes an input image and varies the background based on the prompted input. 


### Running Omni Gen Model
Please follow the following steps to run the omni gen model.
1. First create a virtual environment and install all the requirements as in the requirements.txt file.
2. Clone the OmniGen Repository https://github.com/VectorSpaceLab/OmniGen.git and navigate to the OmniGen directory
3. copy_paste the new_pipe.py and the LoRA checkpoint within the omnigen directory
4. To run only omnigen, run app.py file contained within the same directory but if u want the modified one, use new_pipe.py
